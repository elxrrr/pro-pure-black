# Pro Pure Black for VirtualDJ

A pure-black version of VirtualDJ’s **Pro** layout, made to blend into a black desktop.

**[Generate your skin →](https://elxrrr.github.io/pro-pure-black/)**

Choose your toolbar, logo and palettes in one live preview.

- **Toolbar:** toggle Sandbox, Shoutout, Event Scheduler, Account, Master, CPU, battery and clock. Reorder the toolbar buttons.
- **Colours:** mix existing presets or add your own colours for decks A–D. Default is always included with its original colours.
- **Logo:** add a transparent PNG and choose whether it follows the palette colour.

![Pro Pure Black fullscreen notch layout](screenshots/notch-layout.jpg)

## Deck colours

All themes keep `#000000` backgrounds. Rendered previews show decks **A, B, C, D**, with contrasting colours within the A/B and C/D pairs. Default retains Atomix’s original order.
