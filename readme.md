# Pro OLED for VirtualDJ

A pure-black version of VirtualDJ’s **Pro** layout, made to blend into a black desktop.

![Pro OLED decks and toolbar](screenshots/decks-and-toolbar.jpg)

## Features

- Black backgrounds across the decks, mixer, waveforms and browser.
- Visible grey phrase-sync indicators, beat counters and jog-wheel details.
- Sandbox, Shoutout, Event Scheduler and the account box hidden from the toolbar.
- Layout, status and Settings grouped on the right on macOS.
- Tap, Edit and beat-grid controls always visible; clicking BPM does not toggle them.
- A small VirtualDJ logo beside the window controls.
- Original deck colours and remaining controls retained.

## Install

1. Download **[Pro-OLED.zip](https://github.com/elxrrr/virtualdj-pro-oled/releases/latest/download/Pro-OLED.zip)** from the latest release.
2. Copy it, still zipped, into your VirtualDJ **Skins** folder. On macOS this is usually `~/Library/Application Support/VirtualDJ/Skins/`; some installations use `~/Documents/VirtualDJ/Skins/`. **Settings → Interface → Edit this skin** opens the folder VirtualDJ actually uses.
3. Select **Pro OLED** in **Settings → Interface**. Select **OLED Black** in the layout menu’s colour scheme options if needed.
